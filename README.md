
# Todo Project 

A simple and responsive Todo App built using **HTML, CSS, and Vanilla JavaScript**.

This project allows users to:

- Add tasks
- Mark tasks as completed
- Undo completed tasks
- Delete tasks dynamically

---

## Features

- Add new tasks
- Mark tasks as completed
- Undo completed tasks
- Delete tasks
- Responsive and clean UI
- Instant DOM updates using JavaScript

---

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript

## How It Works

### 1. Add Task
- User enters a task in the input field
- Clicking the **Add** button stores the task in an array
- The UI updates automatically

### 2. Complete Task
- Clicking the **Done** button toggles the completed state
- Completed tasks get a line-through effect

### 3. Delete Task
- Clicking the **Delete** button removes the task from the array
- The list refreshes instantly
